## 模拟模式诚实性验证

- `text_configured=false`、`image_configured=false`（未配置 API）时启动，健康检查如实返回。
- 所有生成任务 `is_simulated=true`，审核引擎自动生成 high 级「模拟演示内容，禁止直接发布」审核项。
- 未配置 API 时调用单字段重生成返回明确中文错误，不会伪造模型调用结果。
