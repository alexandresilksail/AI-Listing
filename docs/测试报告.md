### 安全（test_security.py，V1.1 新增，68 项）

**鉴权（33 项）**：公开端点（health/meta）免令牌可访问；28 个管理端点（商品/文件/Listing/SEO/图片/审核/任务/导出/设置/规则/演示种子）无令牌一律 401；错误令牌 401；Bearer 方式 200；正确令牌 200；设置接口永不返回明文 Key。

**越权与 IDOR（8 项）**：不存在的商品/任务/版本返回 404（不泄露存在性）；参数、图片、导出文件、生成图的 IDOR 均被阻断；`ref_image_ids` 限制在本商品范围内。

**SSRF（18 项）**：非 HTTP 协议拒绝；内网/环回/链路本地/云元数据 169.254.169.254/IPv6 ULA/0.0.0.0 全部拒绝；公网 HTTPS 放行；图像适配器 `_decode` 对 URL 输入同样过 SSRF 校验；本地 mock HTTP 服务器可正常下载（证明不放纵合法请求）；b64 非图片内容拒绝。

**上传加固（6 项）**：合法 PNG 接受；伪造扩展名拒绝；不支持扩展名拒绝；损坏图片拒绝（PIL 解码验证）；超大上传拒绝；像素数上限（防解压炸弹）。

**密钥脱敏（3 项）**：`mask_secret` 单测；「测试连接」错误信息不泄露 Key；调用日志不泄露 Key。

**生产 fail-fast（2 项）**：`PL_ENV=production` + 无令牌 → 子进程启动失败并退出；有令牌 → 正常启动。

### 可靠性（test_reliability.py，V1.1 新增，16 项）

**Worker 可靠性（2 项）**：worker 执行异常被记录且队列继续存活；任务超时被标记 failed。

**重启恢复（2 项）**：重启后 pending 任务重新入队执行；重启后 processing 任务标记 failed（不留僵尸）。

**并发去重（1 项）**：5 线程并发提交相同任务只创建一个。

**预算控制（3 项）**：日预算超限阻止执行；预算检查持锁（防并发穿透）；当日已花费统计忽略未知费用（不当 0 计入）。

**未知费用（4 项）**：未知文本/图像模型 `estimate_cost` 返回 None（绝不返回 0）；allow/block 策略生效；任务总览报告未知费用调用数。

**供应商兼容（4 项）**：按模型尺寸映射（dall-e-3 等仅支持特定尺寸）；不支持的画幅抛明确错误；JSON 模式可配置；未配置 API 时模拟模式保留。
